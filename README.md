
# 远讯小程序商城 php后端

## 项目简介

php后端使用webman框架

改.env配置文件

執行 composer install

將database/yxshop.sql 和database/app.sql 導入到mysql中

Windows下雙擊start.bat啟動

Linux下執行 php start.php start // 啟動

Linux下執行 php start.php stop // 停止

Linux下執行 php start.php restart // 重啟

Linux下執行 php start.php status // 查看狀態
